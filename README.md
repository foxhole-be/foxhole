# Foxhole

Eerste versie van de homepage: kort, warm en co-creatief.

## Bekijken

Open `index.html` in een browser. Er is geen build-stap of server nodig.

## Structuur

```
index.html                     homepage
css/style.css                  stijl + design tokens
assets/images/               illustraties (later: galerij)
design/01-visuele-richting.md ontwerpbeslissingen
```

## Aanpassen

- **Teksten:** rechtstreeks in `index.html`, per sectie.
- **Kleuren en typografie:** de variabelen bovenaan `css/style.css`.
- **Illustratie:** `assets/images/foxhole-landschap.svg` is loss te bewerken
  in elke teksteditor of vectorprogramma.
- **Later:** extra scènes komen als losse SVG's in `assets/images/` terecht;
  een galerij kan daar los van deze homepage op bouwen.
